수행평가 결과물과 세특 자료를 한곳에 보관하고, 일정을 등록하면 마감이 다가올 때 알려드려요. 평가기준을 입력하면 준비 방향도 제안해드립니다.

⚙️ 처음 사용하시나요? (Firebase 설정 안내)

이 사이트는 서버 없이 동작하는 정적 사이트라, 데이터 저장을 위해 Firebase(무료)를 직접 연결해야 합니다.

  1. Firebase 콘솔에서 새 프로젝트를 만드세요.
  2. Authentication → Sign-in method에서 Google 로그인을 사용 설정하세요.
  3. Firestore Database를 생성하세요 (프로덕션 모드로 시작해도 됩니다).
  4. Storage를 생성하세요 (수행평가 결과물 파일 첨부용).
  5. 프로젝트 설정 → 일반 → "내 앱"에서 웹 앱을 추가하고, 나오는 firebaseConfig 값을 js/firebase-config.js 파일에 붙여넣으세요.
  6. Firestore와 Storage의 보안 규칙을 firestore.rules, storage.rules 파일 내용대로 설정하세요 (본인 데이터만 본인이 접근 가능하도록).

설정을 마치기 전까지는 로그인 버튼이 동작하지 않아요.
